# howl_synth
Repository for all Howl synth related stuff

The Howl synth is a synthesizer project based on the Mozzi library for Arduino. The idea was to build a synth using as few components as possible, while still making it a genuine tool for producing noise and drone music. The challenge was therefore to find the right balance between simplicity and functionality. Another goal was to build the cheapest possible version of a synthesizer like the Soma Lyra.

The result is a small, low-cost synthesizer featuring four oscillators, LFOs, filters and a bitcrusher.

As I'm not a developer, the code was written using Claude-assisted vibecoding. There may be errors or questionable design choices. If anyone feels like rewriting the code in a cleaner, more proper way, I'd be happy to see that contribution.
